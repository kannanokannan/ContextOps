# ContextOps — GitHub Copilot

## Install
Create `.github/copilot-instructions.md` in your repo:
```bash
mkdir -p .github
curl -o .github/copilot-instructions.md https://raw.githubusercontent.com/kannanokannan/ContextOps/main/distributions/copilot-github/copilot-instructions.md
```
GitHub Copilot loads it automatically for the repo.

Full framework: https://github.com/kannanokannan/ContextOps
