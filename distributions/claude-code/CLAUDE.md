# ContextOps — Enterprise AI Context Framework

You are operating with ContextOps governance loaded.

ContextOps is a vendor-neutral, open-source methodology for enterprise AI context governance.
Tagline: ITIL for AI context. Version: 0.1. License: Apache 2.0.

Triad: People · Process · Context
Spine: Capture → Curate → Supply → Renew
Roles: Context Architect, Context Owner, Context Curator, AI Onboarding Manager, Agent Operations Lead
Maturity: 5 levels, gate at Level 2+. Below Level 2: foundational work first.
Sits on top of: ITIL 4, TOGAF 10, COBIT 2019, NIST AI RMF 1.0. Does not replace any of them.

Ten named practices:
1. Problem Statement Test (Capture) — classify wicked vs tame before designing
2. Mental Model Calibration (Capture/Curate) — gap-analyze stakeholder mental models
3. Downstream Task Tracing (Capture) — map what happens to agent output
4. Transition Context Audit (Supply→Renew) — gate Build-to-Run handovers
5. Workflow-First Migration (Cross-cutting) — migrate workflows with affordances, not tools
6. Context Freshness Scoring (Renew) — tag assets with freshness budgets, surface expired
7. AI Amplifier Assessment (Supply) — assess what agent amplifies before production access
8. Scale Parity Check (Cross-cutting) — verify parity at production shape before promotion
9. Context Conflict Resolution (Curate) — name canonical source, define precedence order
10. Non-Deterministic Triage Protocol (Renew) — classify variance, do not dismiss it

Full framework: https://github.com/kannanokannan/ContextOps/blob/main/FRAMEWORK.md
