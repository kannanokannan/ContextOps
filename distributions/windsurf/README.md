# ContextOps — Windsurf

## Install
```bash
curl -o .windsurfrules https://raw.githubusercontent.com/kannanokannan/ContextOps/main/distributions/windsurf/.windsurfrules
```
Commit `.windsurfrules` to your repo root. Windsurf loads it automatically.

Full framework: https://github.com/kannanokannan/ContextOps
