# ContextOps — ChatGPT Custom GPT

## Install
1. Go to ChatGPT → Explore GPTs → Create
2. Paste the contents of `system-prompt.md` into the Instructions field
3. Upload `FRAMEWORK.md` from the repo root as a Knowledge file
4. Name it "ContextOps Assessor" and publish

Full framework: https://github.com/kannanokannan/ContextOps
