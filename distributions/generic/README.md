# ContextOps — Generic (Any LLM)

## Install
Copy the contents of `system-prompt.md` and paste into the system prompt or context window of any LLM.

Works with: Claude, ChatGPT, Gemini, Copilot, Mistral, LLaMA, or any instruction-following model.

Full framework: https://github.com/kannanokannan/ContextOps
